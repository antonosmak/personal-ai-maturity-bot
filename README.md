# Personal AI Maturity Bot — Release v1.0

Релізна версія Telegram-бота для самооцінювання персональної AI-зрілості.

## Основна логіка
- стартовий екран із кнопками;
- 4 необов'язкові класифікаційні питання;
- 48 тверджень у 8 вимірах D1–D8;
- шкала 0–5;
- автоматичний розрахунок PAIMI;
- рівні I–V;
- персональний профіль D1–D8;
- рекомендації щодо підвищення рівня персональної AI-зрілості;
- PDF-звіт;
- передавання псевдонімізованих результатів у Google Sheets (`RESULTS` + `ANSWERS`);
- після завершення: «Дякую за увагу!» → базове меню.

## Стартове меню
- `▶️ Розпочати оцінювання`
- `ℹ️ Про інструмент`

Команди журналу та повторного отримання останнього PDF у релізі v1.0 не використовуються.

## Render
Build Command:
`pip install -r requirements.txt`

Start Command:
`gunicorn --bind 0.0.0.0:$PORT app:app`

Environment variables:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_WEBHOOK_SECRET`
- `GOOGLE_SHEETS_WEBHOOK_URL`
- `GOOGLE_SHEETS_WEBHOOK_SECRET`

`RENDER_EXTERNAL_URL` встановлюється Render автоматично.

## Приватність
До Google Sheets не передаються ПІБ, Telegram username або Telegram ID користувача.
Дослідницький набір зв'язується через випадковий `Test_ID`.
